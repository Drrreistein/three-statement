📐 三张表是什么 & 怎么连 先搞懂

利润表 = 一段时间「赚了多少」的录像（看趋势）；
资产负债表 = 某一时刻「家底多厚」的照片（看存量）；
现金流量表 = 同期「真金白银进出」的银行流水（看钱是否真到手）。
展开：三条核心勾稽链（建模的灵魂）

① 利润表 → 资产负债表：本年净利润（扣分红后）滚入「留存收益」。
② 现金流量表 → 资产负债表：现金净变动加到「货币资金」上。
③ 资产负债表 → 利润表：折旧（减净值）计费用、借款利息计财务费用、应收/存货/应付的变动在现金流里调整。
④ 资产负债表 → 现金流量表：资本开支是投资现金流出，分红是筹资现金流出。
只要这四条链写对，三张表必然「勾稽平衡」——这正是下面校验面板的含义。

📐 公式速查表 三表 + 勾稽 + 比率

单位：万元。左侧面板以「%」输入的假设（毛利率、各项费率、税率、周转天数、资本开支率、分红率、利率、增长率）在代入公式前已转成小数。下标 t 表示第 t 年，t−1 表示上一年；t0 为基期。

利润表公式（第 1…N 年）
行项公式说明
营业收入rev_t = rev_{t−1} × (1 + g)g=收入年增长率
营业成本cogs_t = rev_t × (1 − gm)gm=毛利率
毛利gp_t = rev_t − cogs_t
税金及附加taxAdd_t = rev_t × taxAddRate
销售费用sell_t = rev_t × sellRate
管理费用admin_t = rev_t × adminRate
研发费用rd_t = rev_t × rdRate
财务费用(利息)interest_t = debt_{t−1} × i按期初借款计息，借款本模型不变
营业利润op_t = gp_t − taxAdd_t − sell_t − admin_t − rd_t − interest_t
利润总额pretax_t = op_t本模型无营业外收支
所得税费用tax_t = pretax_t>0 ? pretax_t × taxRate : 0亏损不提所得税
净利润ni_t = pretax_t − tax_t
归属母公司净利润np_t = ni_t无少数股东损益
资产负债表公式
行项公式说明
应收账款ar_t = rev_t × dso / 365dso=应收周转天数
存货inv_t = cogs_t × dio / 365dio=存货周转天数
固定资产原值grossPPE_t = grossPPE_{t−1} + capex_t
资本开支capex_t = rev_t × capexRate同时是投资现金流出
年折旧dep_t = grossPPE_{t−1} / depYears期初原值直线法
累计折旧accumDep_t = accumDep_{t−1} + dep_t
固定资产净值netPPE_t = grossPPE_t − accumDep_t
应付账款ap_t = cogs_t × dpo / 365dpo=应付周转天数
借款debt_t = debt_{t−1}本模型借款不变
股本share_t = share_{t−1}不变
留存收益re_t = re_{t−1} + ni_t − div_t净利润扣分红滚存
货币资金cash_t = cash_{t−1} + dCash_tdCash 来自现金流量表
资产总计assets_t = cash_t + ar_t + inv_t + netPPE_t
负债合计liab_t = ap_t + debt_t
所有者权益合计equity_t = share_t + re_t
基期留存收益(倒算)re_0 = (cash0+ar0+inv0+netPPE0) − (ap0+debt0) − share0保证基期平衡
现金流量表公式（间接法）
行项公式说明
净利润= ni_t取自利润表
加：折旧= dep_t （即 grossPPE_{t−1} / depYears）非付现，加回
减：应收增加dAR_t = ar_t − ar_{t−1}占用现金
减：存货增加dInv_t = inv_t − inv_{t−1}占用现金
加：应付增加dAP_t = ap_t − ap_{t−1}释放现金
经营活动现金流净额cfo_t = ni_t + dep_t − dAR_t − dInv_t + dAP_t
购建固定资产= −capex_t
投资活动现金流净额cfi_t = −capex_t
分配股利= −div_tdiv_t = ni_t × payout（ni>0 时）
筹资活动现金流净额cff_t = −div_t无新增/偿还借款
现金净增加额dCash_t = cfo_t + cfi_t + cff_t
期初现金= cash_{t−1}
期末现金endCash_t = cash_t = cash_{t−1} + dCash_t与 BS 货币资金相等
三表勾稽（联动）公式
  1. 利润表→资产负债表：re_t = re_{t−1} + ni_t − div_t（净利润扣分红滚入留存收益）
  2. 现金流量表→资产负债表：cash_t = cash_{t−1} + (cfo_t + cfi_t + cff_t)（现金净变动加到货币资金）
  3. 资产负债表恒等式：assets_t = liab_t + equity_t（校验行「资产−负债−权益」应恒为 0）
  4. 现金勾稽：现金流量表期末现金 = 资产负债表货币资金
  5. 折旧三重出现：利润表(费用抵减) → 资产负债表(累计折旧累加、净值减少) → 现金流量表(加回)
  6. 资本开支双重出现：资产负债表(原值增加) → 现金流量表(投资现金流出)
